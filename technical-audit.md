# Shinri Hub 26.11.23196 — технический аудит

Проверка проводилась 20–21 ноября 2026 года на Windows 10 Pro x64, сборка 19045. См. также [статический аудит установщика](installer-audit.md).

## Оценка

**Доказательств вредоносной активности в проверенном сеансе не найдено.** Подтверждены запрос страны по IP до показа согласия, передача постоянного случайного идентификатора обновлятора, взаимодействие с Discord SDK и сохранение пользовательских данных в локальных журналах.

Аудит выявил риски в доставке игрового кода, контроле целостности локальных файлов и правах на папку установки. С учётом этих результатов автор отчёта рекомендует тестировать эту сборку в отдельной виртуальной машине с тестовым профилем Windows и Steam.

## Что проверено

- Изучены ASAR, JavaScript, настройки, индексы BOX и GMAD, метаданные и цифровые подписи исполняемых файлов. В инвентаризацию вошли 8 DLL Hub вне ASAR и 51 DLL игрового клиента. Для выбранных участков нативного кода изучались импорты и дизассемблированные инструкции.
- Записаны первый запуск Hub, запуск игры и вход в лобби. Использовались список процессов, TCP-соединения, кэш DNS, локальные журналы, изменения файлов и Chromium NetLog.
- NetLog охватывает первые 20 секунд запуска Hub. Игровой TLS не расшифровывался, удалённые адресаты UDP не записывались. Аудит охватывает конкретный образец и наблюдавшийся сеанс.

## Сеть и приватность

| Что наблюдалось | Что следует из наблюдения |
| --- | --- |
| Определение страны | При отсутствии сохранённого региона Hub обращается к `ipinfo.io` до показа согласия. Сервис видит внешний IP. |
| Проверка обновлений | Запрос к серверу обновлений содержит случайный идентификатор, который сохраняется между запусками. Это позволяет связывать проверки из одного профиля. |
| Сервисы Shinri | Hub получает данные для интерфейса и проверяет доступность сервисов. Игровой клиент получает контент, а при входе в лобби используются сервисы группы, наград и магазина. |
| Внешние ресурсы | В первом запуске зафиксированы загрузка шрифта Google Fonts и изображений блога Shinri. Блог прислал заголовки `Set-Cookie`. Отправка этих данных обратно в записанном сеансе не наблюдалась. |
| Discord Rich Presence | Зафиксировано соединение с сервисом Discord SDK. В настройках по умолчанию включён показ сервера и статуса. Никнейм, UID и персонаж по умолчанию выключены. Фактически опубликованные поля в захвате не определены. |
| Журналы лобби | Локально записывались отображаемое имя, внутренний ID, SteamID64, Discord ID, аватар и состояние группы из ответа сервера. Состав исходящего запроса по этой записи установить нельзя. |

В доступном захвате, журналах и проверенном коде не найдено подтверждения отправки данных в Яндекс Метрику, AppMetrica или Yandex Cloud. Также не найдено подтверждения кражи паролей или выгрузки личных файлов. Клиентский захват не показывает, куда получатели могут пересылать данные после приёма.

## Доставка игрового кода и целостность

- Наблюдалась загрузка игровых пакетов по HTTPS. Анализ кода выявил возможность перехода на HTTP. В записанном сеансе переход не наблюдался.
- Анализ загрузчика подтвердил, что он может исполнять Lua из загружаемых пакетов. В проверенной цепочке есть проверка контрольной суммы. Криптографическая подпись игрового пакета не подтверждена. Какие конкретно Lua-файлы исполнялись во время захвата и какие данные они отправляли, не установлено.
- Подпись дистрибутива проверена. В установленном приложении проверка целостности ASAR при запуске отключена, а права на проверенной папке допускают изменение ресурсов обычными локальными пользователями. Проверенные файлы совпадали с дистрибутивом.
- Hub автоматически проверяет наличие обновлений. Во время записи обновление не устанавливалось.

## Изменения в Windows и Garry’s Mod

- Hub регистрирует обработчик ссылок `st://`. Записей автозапуска Hub в проверенных разделах реестра, папках запуска, задачах и службах не обнаружено.
- Игровой клиент использует общие с обычным Garry’s Mod папки конфигурации, данных и настроек. В тесте зафиксирована запись общего файла конфигурации и создание игровых данных в общей папке. Точный перечень изменённых настроек не установлен, поскольку исходного снимка не было.

## Что стоит исправить

1. Использовать HTTPS для всей доставки игрового кода и проверять криптографическую подпись пакетов перед загрузкой в игру.
2. Ограничить запись в папку установки и включить проверку целостности игровых ресурсов и ASAR при запуске.
3. Описать внешних получателей данных, дать управление определением региона и Discord Presence, исключить пользовательские идентификаторы из обычных журналов.
