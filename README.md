# Технические аудиты Shinri Hub

Два отчёта о сборке **26.11.23196**, проверенной 20–21 ноября 2026 года на Windows 10.

| Отчёт | Что внутри |
| --- | --- |
| [Технический аудит Hub и игрового клиента](technical-audit.md) | Сетевые обращения, приватность, доставка игрового кода, целостность файлов и общие данные с Garry’s Mod. |
| [Статический аудит установщика](installer-audit.md) | Подпись и состав пакета, поведение при установке и обновлении, права доступа и очистка при удалении. |

В проверенной записи работы Hub и игры не обнаружено доказательств вредоносной активности. Подтверждены запрос страны по IP до показа согласия, повторное использование идентификатора обновлятора и запись пользовательских данных в локальные журналы. Статический разбор установщика выявил риск в процессе обновления на проверенной конфигурации Windows. Границы каждого вывода описаны в соответствующем отчёте.

Это версии для открытой публикации. В них сохранены результаты, методика и границы проверки. Локальные пути и технические подробности, облегчающие эксплуатацию, опущены.
